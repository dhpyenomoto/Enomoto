# スライドパズル

タイルを並べ替えて、左上から順番に数字を揃えるクラシックな15パズル。ブラウザだけで動く、依存ライブラリなしのバニラ JavaScript 製です。

## 遊び方

`index.html` をブラウザで開くだけです。

```bash
# 簡易サーバーで開く場合
python3 -m http.server 8000
# → http://localhost:8000 にアクセス
```

## 機能

- **盤面サイズの切り替え**: 3×3 / 4×4 / 5×5
- **必ず解ける配置**: 空きマスからの合法手だけでシャッフルするため、詰みになりません
- **操作方法**
  - 空きマスに隣接したタイルをクリックして移動
  - 矢印キーでも移動可能
- **手数カウント** と **タイマー**（最初の操作で自動スタート）
- クリア時にリザルト表示
